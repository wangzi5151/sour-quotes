# 每日毒鸡汤 - 语录贡献指南

感谢你愿意投喂毒鸡汤 💀 本指南教你如何添加一条新的毒鸡汤语录。

## 格式

所有语录存放在 `src/data/quotes.js`，结构如下：

```js
{ text: '语录正文', cat: '分类', tag: '标签' }
```

- **text**: 语录正文（必填）
- **cat**: 分类，必须是以下之一：
  - `life` 生活
  - `love` 爱情
  - `work` 工作
  - `dream` 梦想
  - `social` 社交
  - `money` 金钱
- **tag**: 情绪标签，建议使用已有标签：
  - `扎心` / `真相` / `哲理` / `单身` / `金钱` / `安慰`

## 添加步骤

1. 打开 `src/data/quotes.js`
2. 在对应分类数组的末尾追加一行，例如：

```js
{ text: '你以为你在努力，其实你只是在假装努力。', cat: 'life', tag: '扎心' },
```

3. 提交 PR，或直接告诉我即可

## 语录质量要求

- 一条一条投喂，宁缺毋滥
- 短小精悍（建议 ≤ 40 字），适合截图传播
- 扎心但不恶毒，好笑但不冒犯
- 避免政治、歧视、低俗内容

## 添加新分类

如果语录明显不属于现有分类，可以新增分类：

1. 在 `quotes.js` 的 `CATEGORIES` 数组中添加 `{ id: 'xxx', name: '分类名', emoji: '🍀' }`
2. 在 `QUOTES` 中添加对应的语录（`cat: 'xxx'`）
3. 若用到新标签，在 `TAG_COLORS` 中添加配色
