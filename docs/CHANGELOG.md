# 发行说明 - SourQuotes 每日毒鸡汤

## v1.1.0 (2026-08-29)

**UI 大升级 + 全新功能**

### ✨ 新图标
- 全新设计的「扎心柠檬」图标：渐变底色 + 嫌弃表情 + 头顶毒液滴，更有记忆点
- 生成适配 Android 各尺寸的 192px / 512px PNG

### 🎨 UI 全面美化
- 5 套主题配色：暗黑 / 午夜 / 日落 / 森林 / 明亮，一键切换并持久化
- 毛玻璃底部导航、背景光晕装饰、卡片悬浮动画
- 语录卡片支持滑动切换（左右滑动）
- 更精致的按钮动效与反馈

### ⚡ 流畅度优化
- 使用 CSS transform 动画（GPU 加速）+ will-change
- 减少重排重绘，动画性能大幅提升
- 支持系统「减少动态效果」设置

### 🆕 新功能
- 🔥 **每日打卡**：连续打卡记录 + 7 天日历视图
- 🔔 **每日提醒**：本地通知定时提醒（需授权，原生支持）
- 🔊 **语音朗读**：TTS 朗读语录（支持 Web / 原生）
- 🖼️ **分享卡片图**：一键生成 1080x1440 精美分享卡片，可保存/分享到朋友圈
- 📤 **导出收藏**：一键复制收藏语录
- 🎨 **主题切换**：5 套配色

### 📚 语录库
- 语录扩充至 **140+ 条**
- 新增大量「真相」与「安慰」标签内容

### 下载
- `SourQuotes.v1.1.0.apk` - Android 安装包（约 4.0 MB）
